# איפוס מלא של המערכת — התחלה נקייה

מוחקים את כל המשתמשים ואת כל נתוני העבודה, ומשאירים רק את חשבון הניהול שלך (office@nivcomp.co.il) כדי שתוכל להמשיך להתחבר.

## מה יימחק

- כל חשבונות המשתמשים חוץ מחשבון הניהול — כרגע: `nivcomp@gmail.com` ו-`office@chatbot-sales.co.il` (כולל הכניסה שלהם למערכת).
- כל הלקוחות (5), הספקים (3) והפרופילים המקצועיים שלהם.
- כל הפרויקטים (5) וכל מה שתלוי בהם: אפיונים, דרישות, הנחות, סקופ, הצעות מחיר ותרחישים, תמחור, לוחות זמנים, אישורים, בקשות שינוי, תשלומים, שעות, שיוכי ספקים, דיווחי זמן, קבצים ועדכוני התקדמות.
- כל השיחות וההודעות — צ'אט פרויקטים, שיחות ה-AI, וזיכרון ה-Copilot.
- כל רישומי ה-AI: טיוטות, סיכומים, שימוש, מטמון, התראות, יומני ביקורת ותור פעולות.
- כל ההרשמות הציבוריות, ההזמנות, מצבי ה-onboarding ויומני הפעילות.

## מה יישאר

- חשבון הניהול שלך והפרופיל שלו.
- כל מבנה המסד, הרשאות ה-RLS, ה-Edge Functions וקוד האפליקציה — ללא שינוי.
- הגדרות הקישורים הציבוריים (`registration_settings`), כולל הקודים הסודיים — כדי שקישורי ההרשמה ימשיכו לעבוד. אם תרצה קודים חדשים, נחליף גם אותם.

## איך זה יתבצע

מחיקה אחת מסודרת מול מסד הנתונים, לפי סדר התלויות (קודם רשומות תלויות ואז לקוחות/ספקים/פרויקטים), ולבסוף מחיקת חשבונות ההתחברות עצמם מ-Auth דרך פונקציית שרת מנהלית עם מפתח השירות — מכיוון שאין גישה ישירה לסכימת ה-Auth מהמסד.

לאחר המחיקה נריץ בדיקה שמאשרת: נשאר פרופיל אחד בלבד, אפס לקוחות/ספקים/פרויקטים/הודעות, ואפס משתמשי Auth מלבד חשבון הניהול. נריץ גם `pnpm run build` ונוודא שהמסכים נטענים ריקים בלי שגיאות.
