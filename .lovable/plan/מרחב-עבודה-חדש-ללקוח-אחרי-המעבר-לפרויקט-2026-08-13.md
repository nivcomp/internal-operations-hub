# מרחב עבודה חדש ללקוח אחרי המעבר לפרויקט

המטרה: אחרי שאתה מאשר ליד → פרויקט, הלקוח נכנס למסך אחד נקי, יפה ובשפה שלו — בדיוק בסגנון חלון השיחה של האפיון, בלי תחושת "מסך לידים".

## מה הלקוח יראה

מסך אחד, שלושה אזורים:

```text
+---------------------------------------------------+
|  שם הפרויקט            עברית | English   מסך מלא  |
+------------------------------+--------------------+
|                              |                    |
|   חלון שיחה גדול             |  התרשים החי        |
|   (אותו עיצוב של האפיון)     |  של הפרויקט        |
|                              |  (לחיץ)            |
|   [+]  שלח הודעה             |                    |
+------------------------------+--------------------+
```

1. **חלון שיחה גדול** — הרכיב הקיים של השיחה, בגודל מלא, ממשיך את אותה שיחה מהאפיון. בלי לשוניות מרובות ובלי כרטיסים מפוזרים.
2. **כפתור אחד להעלאה** — כפתור `+` יחיד בתוך שורת ההקלדה: תמונות, PDF, Word. הקובץ נשמר לפרויקט, גם אתה רואה אותו וגם ה‑AI משתמש בו לאפיון.
3. **עברית/אנגלית** — מתג אחד למעלה. השפה נזכרת לפי המשתמש, וברירת המחדל נקבעת מהשפה שבה הוא כתב עד עכשיו (כולל בשיחת הליד). כל הממשק והתשובות של ה‑AI עוברים יחד איתו.
4. **תרשים התקדמות שמתאים לסוג הפרויקט**:
   - בוט / אוטומציה → עץ זרימה עם ענפים בסגנון n8n (טריגר → צעדים → מערכות).
   - אפליקציה / אתר → תצוגת המסכים של מה שבונים.
   - משולב → העץ, וכשלוחצים על צומת "אפליקציה" נפתחת תצוגת המסכים.
5. **צמתים לחיצים** — לחיצה על צומת פותחת חלונית צד עם הסבר בשפה פשוטה: מה הצומת עושה, לאיזו מערכת הוא מחובר (Monday / Airtable / Google Sheets / WhatsApp וכו'), ומה עוד חסר כדי לסגור אותו. לצמתי CRM תוצג תצוגה שמתאימה למערכת שנבחרה בשיחה.

## תיקון "הוא מופיע כליד"

לקוח שכבר קיבל פרויקט לא יראה שום סטטוס פנימי כמו "Lead started". במקום זה יוצג שלב בשפה שלו: "מבינים מה צריך" → "אישור והצעה" → "בנייה" → "מסירה", וגם התווית בסרגל הצד תשתנה לשם החברה שלו במקום התיוג הפנימי.

## פרטים טכניים

- **מסך**: `src/pages/home/ClientHomePage.tsx` הופך למרחב העבודה החדש (`ClientProjectWorkspace`), בנוי משלושה רכיבים חדשים תחת `src/components/client/`. `ClientPortalPage` נשאר לאישורים, תשלומים ומסמכים, ומגיעים אליו מקישור אחד בתחתית המסך.
- **שיחה**: שימוש חוזר ב‑`ProjectChat` הקיים, ללא שינוי בלוגיקת ההודעות; נוספת רק שכבת פריסה ותמיכת שפה.
- **העלאות**: bucket פרטי חדש `project-files` + מדיניות גישה: הלקוח כותב וקורא רק בפרויקט שלו, הסוכנות והספק המשויך קוראים. רישום ב‑`files` הקיים עם `visibility='client_visible'`, וטקסט הקבצים נכנס להקשר של פונקציית `project-chat` לצורך האפיון.
- **תרשים**: רכיב `ProjectFlowCanvas` חדש שמרנדר את ה‑`flow` (nodes/edges) שכבר נשמר בשיחה, בפריסת עץ עם ענפים וצמתים לחיצים, במקום הרשימה השטוחה של `LiveFlowDiagram`. סוג התצוגה נקבע מ‑`prototype_kind` ומזיהוי הטקסט הקיים ב‑`clientWording`.
- **תצוגת מסכים**: לחיצה על צומת אפליקציה פותחת את `PrototypeStudio` במצב לקוח, כפי שהוא היום.
- **שפה**: `language` נשמר לפרופיל המשתמש ומועבר לפונקציות ה‑AI, כך שהתשובות חוזרות באותה שפה.
- לא משתנים: כללי הרשאות, RLS קיים, תמחור, סטטוסים במסד הנתונים, וכל הצד של הסוכנות.

## איך נדע שזה עובד

- לקוח שאושר לפרויקט נכנס ורואה שיחה אחת גדולה, כפתור העלאה אחד, מתג שפה ותרשים חי.
- אין שום מילה פנימית מסוג "ליד", "MVP" או "אפיון" במסך שלו.
- קובץ שהלקוח מעלה מופיע אצלך בפרויקט ומשפיע על תשובות ה‑AI.
- לחיצה על צומת CRM פותחת חלונית שמתארת את המערכת שנבחרה; לחיצה על צומת אפליקציה פותחת את תצוגת המסכים.
- מעבר לאנגלית מחליף גם את הממשק וגם את שפת התשובות, ונשמר בכניסה הבאה.
