# לינק המשך אפיון לפרויקט ספציפי

היום הכפתור בחדר האפיון מייצר את **לינק ההרשמה הכללי** (`/join/client?c=...`) — הוא פותח ליד חדש ולא ממשיך את הפרויקט שהתחלת ידנית בפגישה. נבנה לינק ייעודי לפרויקט: הלקוח פותח אותו, רואה את שם הפרויקט שלו, בוחר סיסמה בלבד (המייל כבר קבוע) ונכנס ישירות לאותו פרויקט.

## איך זה יעבוד

1. בחדר האפיון, הכפתור "לינק ללקוח להמשך אפיון" יפיק לינק חד־פעמי לפרויקט הנוכחי:
   `https://project.stat.ninja/continue?t=<token>`
   אם ללקוח המשויך לפרויקט אין עדיין מייל — תיפתח שורת קלט קטנה להזנת המייל, והוא יישמר על רשומת הלקוח.
2. הלקוח פותח את הלינק ורואה: שם החברה, שם הפרויקט, המייל שלו (לקריאה בלבד) ושדה סיסמה + אימות סיסמה. אין טפסים נוספים.
3. אחרי בחירת סיסמה נוצר חשבון מאומת המקושר לאותו לקוח, הלקוח מחובר מיד ונוחת בפרויקט שלו להמשך האפיון.
4. אם כבר קיים חשבון עם אותו מייל — לא מאפשרים איפוס סיסמה דרך הלינק; מציגים "התחברות" ו"שכחתי סיסמה".
5. הלינק חד־פעמי ופג תוקף אחרי 7 ימים; אפשר להפיק חדש מאותו כפתור.

## פרטים טכניים

- **מיגרציה**: הרחבת `public.onboarding_invitations` בעמודות `project_id`, `expires_at`, `used_at`. ללא טבלה חדשה; ה‑RLS הקיים נשמר (agency admin בלבד), ואימות הטוקן נעשה רק בצד שרת עם service role.
- **access-admin** — פעולה חדשה `projectContinuationLink({ projectId, email? })`: מוודאת שהקורא הוא agency admin פעיל, מאתרת את הלקוח של הפרויקט, משלימה מייל אם נמסר, יוצרת שורת הזמנה עם טוקן ומחזירה את הלינק. ללא שינוי בפעולות הקיימות.
- **public-registration** — שתי פעולות חדשות ללא סשן:
  - `continueInfo({ token })` → `{ valid, company, projectName, email, accountExists }` (חושף רק את הפרטים של אותה הזמנה).
  - `continueActivate({ token, password })` → מאמתת טוקן פעיל ולא מנוצל, יוצרת משתמש עם `email_confirm: true`, יוצרת `profiles` עם role=client ו‑`client_id` של הפרויקט, מסמנת `used_at` ורושמת audit. אם המשתמש כבר קיים — מחזירה `accountExists` בלי לשנות סיסמה.
- **דף חדש** `src/pages/ContinueProjectPage.tsx` + ניתוב `/continue` ב‑`src/App.tsx` באותה תבנית של `/join` (מחוץ ל‑AuthGate), עם הקליינט הציבורי מ‑`publicRegistrationApi.ts` (הסיסמה נשלחת ל‑Edge Function ואז `signInWithPassword`).
- **`src/services/publicRegistrationApi.ts`**: הוספת `continueInfo` ו‑`activateContinuation`.
- **`src/components/meeting/MeetingWorkspace.tsx`**: הכפתור הקיים יקרא לפעולה החדשה במקום ל‑`publicRegistrationLink`; טקסטי ההעתקה ו‑WhatsApp יותאמו לשם הפרויקט.
- ללא שינוי בתמחור, בהרשאות קיימות, בהקצאת ספקים או במסלול ההרשמה הכללי — הוא נשאר כפי שהוא.
