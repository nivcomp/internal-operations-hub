# בלי מושגים מקצועיים בממשק הליד והלקוח

המטרה: הלקוח יראה בכל מקום את מה שהוא מקבל **במילים שלו** (אוטומציה, בוט בוואטסאפ, אפליקציה, אתר) ולא מונחים כמו "MVP", "אב־טיפוס", "אפיון", "Scope", "Change Request".

## מה משתנה

### 1. שכבת ניסוח אחת ללקוח
קובץ חדש `src/lib/clientWording.ts` שמחזיר את שם התוצר לפי סוג הפתרון של הפרויקט (`prototype_kind` הקיים: `app` / `whatsapp` / `automation`):

```text
automation -> "האוטומציה שלך"      / "התהליך האוטומטי"
whatsapp   -> "הבוט בוואטסאפ שלך"
app        -> "האפליקציה שלך"
לא ידוע    -> "מה שבונים לך"
```
בנוסף מיפוי קבוע למונחים: אפיון -> "סיכום מה שביקשת", גרסה -> "עדכון", בקשת שינוי -> "בקשה לשינוי", תצוגה מקדימה במקום פרוטוטייפ.

### 2. פורטל הלקוח (`src/pages/ClientPortalPage.tsx`)
- הטאב "ה־MVP שלי" יקבל את השם לפי סוג הפתרון (למשל "האוטומציה שלך").
- כל הטקסטים: "בקש עדכון MVP", "יש שיחה חדשה מאז גרסת ה־MVP", הודעות ההצלחה — ינוסחו מחדש בלי המילה MVP ("רוצה שנעדכן את האוטומציה?", "עדכנו אותנו ונשלח גרסה מעודכנת").
- אותו דבר בטקסטים באנגלית.

### 3. מסכי הליד/ההצטרפות (`src/components/onboarding/AiOnboardingWorkspace.tsx`)
- הכרטיס בתמונה: "מתקדמים ל־MVP" יוחלף ב"מתקדמים לבנייה" עם הסבר בשפה פשוטה, והמשפט בפתיח יוחלף גם הוא.
- `src/components/client/ClientWorkspaceIdentity.tsx` — הערות הטיוטה/הפרויקט ינוסחו בלי MVP ובלי "אפיון".

### 4. עמוד שיחות הלידים (`src/pages/LeadConversationsPage.tsx`)
רק הטקסטים שהליד עצמו רואה/מקבל ינוסחו מחדש; התצוגה הפנימית של יניב נשארת כמו שהיא (שם אפשר להשאיר מונחים מקצועיים).

### 5. הנחיות ל־AI (טקסט בלבד ב־system prompt)
ב־`supabase/functions/onboarding-chat`, `lead-conversations` ו־`project-chat` (רק בערוץ מול לקוח) תתווסף הנחיה:
- לדבר בעברית פשוטה, בלי מושגים מקצועיים (MVP, אפיון, scope, אינטגרציה, API, פרוטוטייפ).
- לא לשאול שאלות שמכילות מונח מקצועי; לשאול "מה אתה רוצה שיקרה אוטומטית?" במקום "מה ה־Scope?".
- להשתמש במילים שהלקוח עצמו השתמש בהן לתיאור התוצר.
- אם חייבים מונח — להסביר אותו במשפט קצר.

## מה לא משתנה
לוגיקה עסקית, סכימת נתונים, הרשאות, זרימות עבודה, שמות טבלאות/שדות (`prototype_kind`, `prototype_versions`) והממשק הפנימי של יניב — רק טקסטים גלויים ללקוח.

## בדיקה
`pnpm run build`, ואז מעבר על פורטל הלקוח ומסך שיחת הליד לוודא שאין יותר "MVP"/"אב־טיפוס" בשום טקסט שהלקוח רואה.
